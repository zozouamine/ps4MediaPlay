# دليل التحكم - PS4 Media Play

## في متصفح الملفات

| الزر | الوظيفة |
|-----|---------|
| D-Pad ↑ / ↓ أو Left Stick | التنقل بين الملفات |
| X | دخول مجلد / تشغيل ملف |
| O | رجوع للمجلد السابق |
| □ Square | اضافة الى قائمة التشغيل |
| OPTIONS | الاعدادات |
| L1 | الانتقال لـ USB التالي |
| R1 | تحديث القائمة |

## أثناء التشغيل

| الزر | الوظيفة |
|-----|---------|
| X / R3 (الضغط على العصا اليمنى) | Play / Pause |
| O | ايقاف والعودة للمتصفح |
| L2 | ترجيع 10 ثواني (ضغطة متكررة = -30s) |
| R2 | تقديم 10 ثواني |
| L1 | الملف السابق في قائمة التشغيل |
| R1 | الملف التالي |
| D-Pad ← / → | تقديم/ترجيع 5 ثواني |
| D-Pad ↑ / ↓ | رفع/خفض الصوت |
| Triangle /\ | اظهار/اخفاء معلومات الفيديو |
| Square [] | اظهار قائمة التشغيل |
| OPTIONS | اعدادات (ترجمة، سرعة، تكرار) |
| PS | خروج سريع |

## شريط التقدم
- يظهر تلقائيا عند الضغط على أي زر توجيه
- يختفي بعد 3 ثواني من عدم النشاط (مثل YouTube/Netflix)
- يعرض الوقت الحالي / الوقت الكلي
