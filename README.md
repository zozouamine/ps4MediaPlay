# PS4 Media Play - مشغل الوسائط الاحترافي لـ PS4 المعدل

تطبيق Homebrew احترافي لجهاز PS4 المعدل (Jailbreak) يقوم بتشغيل الصوتيات والفيديوهات من USB والهارد الداخلي.

## المميزات
- ✅ تشغيل الفيديو: MP4, MKV, AVI, MOV, FLV, WEBM
- ✅ تشغيل الصوت: MP3, FLAC, WAV, AAC, OGG, WMA
- ✅ متصفح ملفات احترافي (USB + HDD)
- ✅ واجهة تحكم كاملة متوافقة 100% مع يد PS4
- ✅ تحكم كامل: Play/Pause, Seek, Volume, Fullscreen, Subtitles
- ✅ دعم ترجمة SRT
- ✅ قائمة تشغيل Playlist
- ✅ يعمل على جميع الفيرمويرات المعدلة: 6.72 / 7.02 / 7.55 / 9.00 / 9.60 / 11.00

## متطلبات التشغيل
- PS4 معدل (GoldHEN مفعل)
- تثبيت عبر USB أو FTP

## طريقة البناء والتثبيت - انظر docs/INSTALL.md
